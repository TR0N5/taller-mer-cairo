# Taller MER: tienda Cairo

Taller interactivo para aprender el modelo entidad-relación escribiendo código DBML.
Siete misiones con pistas, puntaje y un jefe final: reconstruir el MER completo de Cairo (las 10 tablas de las migraciones, sin las que Laravel trae de fábrica).
Cada relación se lee en palabras (1 → N) y, al vencer al jefe, se desbloquea el botín: el diagrama oficial para descargar (`tienda.dbml`, PNG y SVG).
Todo funciona en el navegador, sin instalar nada.

Abre `index.html` o la página publicada con GitHub Pages.
El puntaje se guarda en el navegador de cada estudiante.
